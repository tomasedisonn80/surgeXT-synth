# Wave 3, agent 16 — effect benchmark and DSP compatibility fixtures

Role: systems engineer and VST DSP validation specialist.

## Implemented

Extended `surge-cpu-bench` with `conditioner`, `eq3`, and `eq11` scenarios. Each
holds eight notes through a real global effect slot loaded using the engine's
parameter API and native defaults, then sets nontrivial stable coefficient inputs.
The Conditioner side highpass is explicitly enabled. Existing benchmark schema 1
is unchanged, including the same setup/timing separation and PCM comparison
contract.

Added `surge-dsp-regression`, a separate offline executable linked to the real
common engine. It accepts `--output-dir DIR` and writes 63 complete stereo f32le
fixtures plus `manifest.json`. The coordinator must compile this exact same
harness against the untouched baseline and candidate engine and compare the full
PCM bytes; a successful render alone is not an equivalence result.

Coverage:

- Conditioner, three-band EQ, and eleven-band EQ with coefficient automation.
- Band deactivation, coefficient changes while disabled, several intervening
  control updates, and reactivation without changing those final target values.
- Effect-slot bypass with parameter changes while bypassed, then reactivation.
- Explicit `suspend()` and `init()` of the live effect, preserving the engine's
  usual parameter-data path and every-block processing.
- Initial sample rates 44.1, 48, and 96 kHz, cycling through all three while notes
  are held. EQ sample-rate transitions occur at each of the eight offsets of its
  existing slow coefficient-update cadence.
- Positive and negative zero gain/cutoff inputs, held for multiple control updates.
- Four lowcut slopes in both scenes, cutoff changes, deactivation/reactivation,
  sample-rate transitions, held notes, releases, and subsequent tail/silence blocks.

Each fixture renders 1,536 engine blocks, releasing notes at block 1,024. The
manifest records sample-rate sequences and transition blocks, frame counts,
canonical-byte FNV-1a fingerprints, and measured peaks. Nonfinite audio and
unexpectedly silent fixtures fail. The same plugin `FPUStateGuard` and explicitly
seeded engine RNGs are used. No fixture modifies factory presets or plugin UI.

## Validation and limits

Reviewed the effect construction/parameter API, native effect enums, Conditioner
deactivation defaults, and sample-rate reset path. Scoped whitespace checks passed.
Native compilation, execution, and baseline/candidate PCM comparison are pending
with the coordinator, as assigned. No build or performance result is claimed.
The effect scenarios provide process-level offline measurements; they do not
establish a host callback deadline guarantee or a universal reduction for all
patches. No commits or remote mutations were performed by this agent.
