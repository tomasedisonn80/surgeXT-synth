selection before and after execution. No preset or production source was changed.

## Limits

This is a bounded audio-equivalence smoke check of ten representative presets,
not audio validation of all 1,000 presets. It does not exhaust macro settings,
tempos, registers, velocities, automation paths or long release tails. The number
of requested notes is not a guarantee of the number of active synthesizer voices.

The short window timings are **not CPU improvement evidence**. Full PCM files are
retained only for the first pair; the second pair uses the validated report
fingerprints. No human musical audition, commercial DAW behavior, real-time
scheduling guarantee or native plugin wrapper compatibility is claimed.

No production edits, compilation, commits, pushes or additional agents were used.
