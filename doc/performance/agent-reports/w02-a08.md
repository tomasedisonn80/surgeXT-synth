# Wave 2 / Agent 8 — engine control-path reductions

Role: systems engineer and VST DSP specialist. Base commit:
`0dcc076937974605095a9567dacd3f28a0b04fd8`.

## Implemented

- Rewrote `SurgeSynthesizer::prepareModsourceDoProcess` to skip inactive scenes,
  clear an active scene's mask once, check the six voice step sequencers directly,
  and set the nine formula-required controller flags only when a formula exists.
  The routing lists are traversed directly without the repeated list-selection
  switch or indexed accesses.
- Hoisted each scene's lowcut frequency conversion out of the cascade loop.
  Every stage still calculates its coefficients and processes its audio on every
  block, preserving independent smoothing and filter history.

Only `src/common/SurgeSynthesizer.cpp` was modified by this assignment, apart
from this report. No persistent caches, new synchronization, or allocations were
introduced.

## Preserved invariants

Inactive scenes retain their previous flags. All twelve LFO shapes participate
in formula detection. Step-trigger masks keep voice LFOs active without routes.
Muted and zero-depth routes still mark their sources; global routes still mark
each active scene regardless of their `source_scene` field. Existing source-ID
assertions remain. Each preparation call observes the current routing state.

All lowcut stages are constructed with the same `SurgeStorage` pointer in the
synthesizer constructor. At pinned `sst-filters` commit
`6bcf08bb8ecd177b161281e8147f30b10f0b5db7`, `BiquadFilter::calc_omega` only reads
the tuning-ignoring pitch conversion and sample-rate inverse. Its adapter calls
`SurgeStorage::note_to_pitch_ignoring_tuning`, a read-only table interpolation,
and reads `dsamplerate_inv`. The hoisted value therefore remains identical for
all cascade stages within a block, including changing cutoff/sample rates.
