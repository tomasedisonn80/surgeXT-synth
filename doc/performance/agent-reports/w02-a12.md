# Wave 2, agent 12 — modulation-mask regression test

Added `src/performance/ModulationMaskTest.cpp` and the standalone
`surge-modulation-mask-test` target under `SURGE_BUILD_PERFORMANCE_TOOLS`.
The target links the common engine, requires no JUCE or test framework, and does
not enter any plugin binary.

The test preserves the original `prepareModsourceDoProcess` control flow from
`0dcc076937974605095a9567dacd3f28a0b04fd8` as an independent test-only oracle.
Every case snapshots the incoming flags, evaluates that oracle, restores the
incoming flags and invokes the actual engine method, comparing every flag in
both scenes. Failure output identifies the case, scene mask, scene and source.

Coverage includes all scene masks with false/true/complementary sentinel flags;
all LFO shapes in all twelve positions; zero, low-bit and high-bit trigger masks;
all six-voice-step trigger combinations; all twelve-formula subsets; all valid
source IDs in each routing list with both source scenes, muted/unmuted state and
zero/positive/negative depths; duplicate dense routes; explicit route-removal and
global-source-scene invariants; and 12,000 deterministic evolving cases that
retain previous flags while changing routes, shapes, triggers and active scenes.

Validation in this assignment: source inspection and scoped `git diff --check`.
Compilation and execution are intentionally left to the coordinator's native
build. No native pass or speedup is claimed here. Run the built executable
directly; no CTest registration or root build configuration was changed.
