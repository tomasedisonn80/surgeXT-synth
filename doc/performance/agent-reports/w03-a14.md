# Wave 3 / Agent 14 — EQ coefficient input caches

Role: systems engineer and VST DSP specialist. Completed source implementation
and review; no build, runtime test, benchmark, commit or push was performed by
this agent.

## Implemented

- `GraphicEQ11BandEffect`: cache each of the eleven gain inputs. Its fixed
  frequency table and bandwidth remain unchanged.
- `ParametricEQ3BandEffect`: cache frequency, bandwidth and gain independently
  for each of the three bands.
- Both caches include `storage->dsamplerate_inv`; a changed sample rate refreshes
  every band at the next existing coefficient-update opportunity. Neither effect
  changes its `slowrate` schedule.
- Float input comparisons require numeric equality and identical representation,
  so NaNs never qualify as unchanged and positive/negative zero remain distinct.
- `setvars(true)` invalidates the cache while retaining the original initialization
  targets and `coeff_instantize` calls. Because `init()` then calls each band's
  `suspend()`, the next `setvars(false)` must recompute all coefficients and run the
  Biquad first-use initialization.

Only coefficient calculation is skipped for unchanged inputs. Audio processing,
coefficient smoothing, output gain/mix, deactivated-band semantics, suspension and
effect tails are unchanged. Cache state is fixed-size effect-owned storage; no
allocations, locks or cross-thread communication were added.

## Source invariants checked

At pinned `sst-filters` revision `6bcf08bb8ecd177b161281e8147f30b10f0b5db7`,
`BiquadFilter::set_coef` initializes values on its first call, then calls
`vlag::newValue`, which only assigns coefficient targets. `vlag::process`, invoked
by audio processing, independently advances smoothing. Reassigning an identical
target therefore has no additional state transition after initialization.

The coefficient functions read only their input values, the sample-rate inverse,
and deterministic pitch/dB lookup tables. The parametric frequency conversion
uses the tuning-independent table, whose entries are only initialized in
`SurgeStorage::init_tables`; scale edits do not alter it. No other code accesses
the private Biquad instances or changes the graphic EQ's frequency table.
