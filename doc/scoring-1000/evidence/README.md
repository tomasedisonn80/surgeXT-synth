# Scoring 1000 technical evidence

The report ZIPs preserve the exact original per-preset JSON bytes. Each report index records its report SHA-256 and corresponding FXP SHA-256. `checksums.json` identifies all files in this export. `integrity-audit.json` recomputes totals and cross-checks native and Python measurements against the current catalog and fixtures. `provenance.json` binds the renderer, source files, recipes, gain adjustments and catalog. Raw JSON/CSV summaries are unchanged.

The five primary gates cover native definition, default audio, performance, expression and stress, and evidence completeness. Optional sustained-note, semantic roundtrip, and factory staging evidence retain their own scopes. Historical correction records are supplementary source evidence; their earlier catalogs remain labeled as such.

Human musical audition remains pending, and composer endorsement is not claimed. These measurements do not establish universal genre suitability, perceptual uniqueness, reconstructed true-peak safety, complete release settling at every macro endpoint, or DAW-host behavior.
