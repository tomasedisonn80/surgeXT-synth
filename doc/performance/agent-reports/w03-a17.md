## Findings

- **Modulation mask:** the stateless rewrite preserves inactive masks, trigger-only
  voice LFOs, all twelve formula positions, the nine formula controller dependencies,
  and muted/zero-depth/global-route marking. The routing mutex remains outside the
  method at its normal audio call site. The independent mask oracle covers the
  relevant value-state combinations.
- **Lowcut:** all stages share the same storage. `calc_omega` only reads the fixed
  pitch lookup and sample-rate inverse; the hoist preserves its arithmetic expression
  and every stage's coefficient setter and processing order. No stage state is reused.
- **Coefficient caches:** pinned Biquad `newValue` only assigns a target; lag advancement
  remains in `process_block`. Cached inputs cover each setter's changing parameter
  dependencies and sample rate. Float keys distinguish signed zero and cannot hit on
  NaN. Both EQs invalidate on initialization before their subsequent filter suspension,
  preserving `first_run`. Deactivated bands retain the original update cadence.
- **Narrow initialization concern:** Conditioner `init()` currently computes targets
  and leaves its cache valid. The synth callback later establishes round-to-nearest
  through `FPUStateGuard`; initialization can occur in another host floating-point
  context. The original first process recalculates targets, while the cache could skip
  that recalculation. Recommend invalidating the Conditioner cache at the end of
  `init()` so the first processing update always runs. This does not reduce steady-state
  savings. This is source-order reasoning, not a reproduced runtime failure. Explicit
  sample-rate-reset invalidation also merits coverage for same-rate table rebuilds.

## Additional regression cases

Beyond static parameters and ordinary rate changes, compare complete baseline/candidate
PCM after changing a deactivated band's inputs, allowing a control update, and then
reactivating it without another value change. Exercise each of the eight EQ control-phase
offsets for a rate change; repeated `init`/`suspend`; a return to an earlier sample rate;
unchanged parameters across effect replacement; and initialization outside the callback's
floating-point mode. NaN coefficient paths already involve unsupported float-to-integer
lookup conversions, so finite-audio tests must not claim to establish safe NaN handling.

## Future held-key scan work

`updateHighLowKeys` scans 128 raw key orders on every requested control block. A future
cache could retain only raw lowest/highest/latest results, invalidated by every constructor,
note-on, and scene-specific note-off write. It must still apply the current keytrack root
and preserve controller `init` calls and last-release behavior. Do not cache the entire
method on MIDI events: keytrack-root automation remains live. The input array is public,
and release routing depends on current scene/split state; ownership and invalidation
should be established before adopting a cache. No further optimization is proposed for
this change set.
