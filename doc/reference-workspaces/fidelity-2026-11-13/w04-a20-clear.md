## Evidence and measured difference

with the [native baseline](../native-gallery/08-clearsignal-accessible.png), both

y633–687 in the reference, versus x1212–1275, y634–697 in the native image.

## Changes

Only the Clear inspector paint branch and Clear manifest were changed:

- Display `RouteRow.normalizedDepth` in a signed 24 px nominal readout. Use
  three decimals below 0.01, matching the matrix's existing precision rule.
- Keep `RouteRow.amount`, generated by the native parameter formatter, in a
  subordinate 12.5 px line. Source and destination names remain unchanged.
- Show actual `bipolar` and `muted` metadata in the compact footer, with a
  light divider. The dark text/high-contrast palette is preserved.
- Change the paint-only inspector plot from `[1211,633,66,66]` to
  `[1214,632,61,57]`, matching the measured tile face. Amount and footer text
  move upward toward the reference's baselines.
- Document normalized versus physical depth in the existing adaptation note.

The inspector remains a readout; its real matrix row provides depth editing.
No imitation slider or reference value was added.
