## Findings and changes

builds `surge-embedded-content-test`, but `src/scoring-tools/CMakeLists.txt` does
not register that executable with CTest. The guide now distinguishes registered

```sh

```

Made four narrow wording corrections in the guide:

- Requested MIDI notes are not an independently measured active-voice count;
  scene configuration and patch voice mode can change that count.
- The reported reduction is the ratio of baseline/candidate medians, not the
  median of per-pair percentage changes.
- Tail timing covers the entire fixed post-release interval, including possible
  idle processing after the audible release has decayed.
- The 63 lifecycle fixtures change stored effect parameters through the normal
  engine copy path. They do not exercise real VST/CLAP host automation queues or
  specifically isolate modulation-only changes with stationary base parameters.

The guide already correctly states that Release/LTO were existing defaults,
PUC headless results do not establish LuaJIT performance, only first-pair complete
PCM is retained by the paired runner, and native host/deadline behavior remains
a separate scope. Preset names, targets, backend settings, minimum versions and
baseline tooling-copy commands agree with their source definitions.
