# Agent 48 — optional render-thread CPU evidence

## Assignment and changes

Systems engineering and VST measurement review, wave 8 of 10. The initial wall
measurements showed scheduler and order sensitivity. The coordinator authorized
an optional CPU-clock extension to the existing paired runner rather than a
second implementation of its process, provenance and PCM checks.

Changed `scripts/performance/run_comparison.py`; added
`scripts/performance/thread_clock.py` and `test_thread_clock.py`.

- `--thread-cpu` is an explicit opt-in. Default wall-report schema, comparison
  mathematics, child execution order and first-pair PCM checks remain unchanged.
- When requested, every child receives a distinct `--thread-output` path. The
  runner preserves the sidecar and records its filename and SHA-256 in provenance.
- The validator requires the exact native schema and
  `CLOCK_THREAD_CPUTIME_ID` clock identifier. It binds sample rate, repetitions,
  frames, block size, channels, seed, scenario coverage, audio-window duration and
  every PCM fingerprint to the corresponding validated wall report.
- Duplicate JSON fields, unknown fields, false success, wrong clocks, malformed
  metadata, missing scenarios, nonfinite/nonpositive timings, count mismatches,
  changed audio and overflowing derived statistics are rejected.
- After existing complete first-pair PCM verification, the runner writes
  `thread-comparison.json` and `thread-summary.txt`. The JSON retains raw CPU
  arrays, medians, ranges and CPU seconds per rendered-audio duration. Reduction
  is `100 * (1 - median(candidate) / median(baseline))`; it is not a median of
  per-pair ratios.

The native writer implemented by agent 47 was inspected and matches this exact
schema. The helper measures CPU charged to the rendering thread and includes
the wall-clock reads around the same processing window. It excludes scheduling
waits and other threads. CPU frequency, cache state and virtualization still
affect results; this is not a hardware-cycle count, DAW meter or deadline test.
