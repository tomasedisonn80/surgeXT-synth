## Findings

No new callback allocation, mutex, retry loop, dynamically initialized function
static, or escaping buffer pointer was found in the reviewed changes.

| Area | Source evidence and conclusion |
| --- | --- |
| Table generation | `SurgeStorage::init_tables()` contains the only storage generation `fetch_add`, at the end of table construction. The three effect `setvars()` implementations each contain one relaxed load. The callback does not increment the counter. |
| Control cadence | `ConditionerEffect::process()` still calls `setvars(false)` once per processed block. Both EQs retain `if (bi == 0)` and `bi = (bi + 1) & slowrate_m1`; `Effect.h` defines `slowrate = 8`. The atomic and FP-control reads therefore occur once per eight EQ blocks. |
| Cache lifetime | Gains, frequencies, bandwidths, generation, sample-rate inverse, FP controls and validity are initialized scalar or fixed-array members of each effect instance. No shared cache, allocation or lazy initialization is added. Reset overrides invalidate one Boolean. |
| Floating-point key | `CoefficientCache.h` reads native control registers and returns two scalar values. The GNU/Clang x86 control-word temporary is automatic storage. ARM's register selector is a constant expression. Unsupported cases retain uncached calculations. No global initialization, environment mutation or library-based environment query is added by this helper. |
| Modulation flags | `prepareModsourceDoProcess()` fills a fixed mask, scans the fixed LFO arrays, and walks existing routing vectors by reference. The nine-controller and three-vector initializer lists do not allocate heap storage or copy vectors. Active-scene work remains linear in existing route count; inactive scenes are skipped. |
| Lowcut | Each scene now computes its common angular frequency once. Every cascade stage still receives its coefficient target and processes the same audio block. No filter storage, slope limit or processing cadence changes. |
| Processor pointers | `processBlock()` retains local JUCE bus views, clears scene buses before acquiring pointers, and performs no resize or bus-view replacement during the sample loop. Main pointers require positive sample count; scene pointers additionally require two channels. Nothing stores a pointer beyond the callback. MIDI and aliased input reads remain before the corresponding output writes. |

The pinned JUCE `AudioBuffer::getWritePointer(int)` is `noexcept`, sets the local
view's clear flag, and returns its channel pointer; it does not allocate. The new
code acquires pointers after the only scene clears and skips acquisition for a
zero-length callback, satisfying the relevant clear-flag lifetime constraint.

## Verification and limits

A tiny C++20 compile-time check of
`std::atomic<std::uint64_t>::is_always_lock_free` passed with the available native
compiler. This establishes the property for this build target; other compiler
and architecture combinations still require their platform validation. No new
claim of universal real-time safety or lower wall time follows from this review.

The relaxed generation counter invalidates caches; it does not publish or
synchronize mutable coefficient tables. Existing callers must still serialize
table mutation with DSP reads. Existing routing-vector access has the same
serialization requirement and variable route-count cost as before. Existing
callback error-reporting, patch/effect lifecycle, GUI MIDI and OSC paths were not
made allocation-free by this change and are outside this narrowly scoped claim.

Complete baseline/candidate PCM comparison, native processor tests and measured
CPU results remain the coordinator's gates.
