# Wave 4, agent 20 — independent DSP fixture review

Role: systems engineer and VST DSP regression specialist.

## Review

Reviewed `DspRegression.cpp` against the actual effect parameter enums, engine
effect-loading API, bypass/disable behavior, sample-rate reset path and lowcut
cascade. The effect fixture checks the instantiated effect and serialized type
after loading. The three-band parameter triplets are gain/frequency/bandwidth,
matching the enum. The Conditioner explicitly enables its side highpass, and
band changes while inactive reach the usual control-rate parameter path before
reactivation. Both scenes exercise all four lowcut slopes.

The existing eight EQ phase offsets remain intact: actual sample-rate changes
occur at blocks `512 + phase` and `768 + phase`, across all three initial rates.
These are differential fixtures, so the same harness must be compiled against
the original and candidate engines. Rendering finite, audible output alone does
not establish compatibility. Error listeners, effect-load checks, finite-sample
checks, peak checks and complete PCM output are retained.

## Changes

- Added a reset to the current numeric sample rate at block `640 + phase`,
  exercising same-rate reset notifications at every EQ control-cycle offset.
- Changed the existing explicit effect initialization at block 448 to run under
  `FE_UPWARD`, with an RAII restoration of the prior callback mode before audio
  processing resumes. This covers initialization outside the callback's normal
  floating-point environment without depending on candidate-only cache fields.
- Added explicit lifecycle metadata to the manifest: `effect_init_rounding`,
  `same_rate_reset_blocks` and `outside_callback_init_blocks`.
- Required the output directory to be absent or empty, preventing accidental
  replacement of baseline evidence or unrelated existing files. The help text
  documents this requirement.

The fixture count stays **63**; each renders 1,536 blocks and releases its notes
at block 1,024. No source presets or production DSP files were changed.

## Verification and limits

Scoped whitespace checks passed. The coordinator owns compilation, execution
and complete baseline/candidate PCM comparison; none was performed by this
agent. Directed-rounding setup checks `fegetround`/`fesetround` support and fails
explicitly if the required mode cannot be established. A same-rate notification
does not necessarily change output by itself; it provides lifecycle coverage,
while the directed initialization targets the identified coefficient-environment
hazard. No performance result, native pass, commit or push is claimed.
