## Practical limits

- Formula subsets are exhaustive for one scene at a time, not the Cartesian
  product of both scenes' 4,096 subsets. The evolving sequence can modify both
  scenes. Production mask calculations are separated by scene except for the
  global route list, whose both-scene behavior also has explicit assertions.
- All six voice trigger-presence combinations are covered. The suite does not
  enumerate all 64-bit trigger values; preparation only distinguishes zero from
  nonzero, and several bit positions plus evolving one-bit masks are tested.
- Routes use valid source IDs. Malformed IDs violate the existing asserted
  production precondition and are not a sound-preservation fixture.
- The suite compares processing flags. LFO state advancement, Lua execution,
  MIDI timing, concurrent route edits, audio output and real-time deadlines need
  their separate engine, PCM and processor gates.

No extra combinatorial test or production change is recommended for this mask
rewrite based on the reviewed evidence.
