# Wave 3 / Agent 18 — build presets and headless engine tests

## Completed changes

- Added CMake preset schema version 3, compatible with the project's CMake 3.22
  minimum. `cpu-release` selects Release and LTO for the existing native plugin
  targets. It retains the default Lua backend and existing portable CPU floor;
  it does not introduce native-CPU flags, AVX, fast-math or DSP quality changes.
- Added `cpu-headless`, selecting Release/LTO, PUC Lua, the offline measurement
  tools, scoring tools and existing engine test runner without JUCE or desktop
  dependencies. Build and test presets use two concurrent jobs.
- Moved `SURGE_BUILD_PERFORMANCE_TOOLS` to the root so `enable_testing()` can run
  at the root for standalone performance tests as well as the normal test runner.
- Enabled the existing engine test runner with JUCE skipped only when performance
  tools are explicitly enabled. Ordinary plugin and Rack-default selection remains
  unchanged. The ordinary JUCE audio-basics dependency is retained when present;
  a source search found no JUCE dependency in the test runner's C++ sources.

## Commands

```sh
cmake --preset cpu-release
cmake --build --preset cpu-release

cmake --preset cpu-headless
cmake --build --preset cpu-headless
ctest --preset cpu-headless
```

Presets require Ninja and the repository's pinned submodules. The plugin preset
also needs the usual platform audio/GUI development dependencies. Platforms that
require PUC Lua can explicitly override `SURGE_LUA_IMPL` according to `libs/lua`'s
existing backend instructions. PUC measurements must be labeled as such; they are
not LuaJIT production measurements. Release and LTO were already enabled by the
repository, so the presets themselves are not a new measured CPU improvement.

`CMAKE_POLICY_VERSION_MINIMUM=3.5` preserves compatibility with older dependency
CMake files when using CMake 4. The performance executables' individual CTest
registrations are separate from root test discovery; at this checkpoint their
CMake file defines executable targets only. Existing engine tests use Catch's
test discovery.
