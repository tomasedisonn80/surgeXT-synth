# Wave 5, agent 28 — complete PCM evidence comparison

Role: systems engineer and VST DSP validation specialist.

## Work completed

Added `scripts/performance/compare_regression.py` and its focused contract tests.
The command compares two distinct output directories from the identical
`surge-dsp-regression` harness:

```sh
python scripts/performance/compare_regression.py \
  /absolute/path/to/baseline-fixtures \
  /absolute/path/to/candidate-fixtures \
  --output /absolute/path/to/comparison.json
```

The comparator requires the complete 63-case suite, strict current manifest fields,
unique safe names, matching lifecycle metadata, valid frame counts and all expected
PCM files. The schema includes the newly added processing-rounding intervals.
Duplicate JSON keys, nonfinite JSON constants, missing/extra fixture fields, missing
or extra PCM files, and filenames or symlinks escaping the evidence directory fail.

Each successful fixture comparison reads both complete files and requires exact
byte equality. It also checks finite float samples, recomputes the FNV fingerprint
and absolute peak against both manifests, and records an independently computed
SHA-256 hash and byte count. There is no audio tolerance. The output records all
fixture metadata, manifest hashes, per-fixture evidence, total compared bytes and
an explicit scope statement. An output path cannot overwrite input manifests or
PCM, including through an existing hard link or symlink alias.
